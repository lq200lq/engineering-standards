# 数据库能力规则

**等级：recommended**

- 数据库结构变更应通过项目采用的 Migration 机制版本化，避免依赖线上手工改结构。
- Migration 应能在项目支持的环境中重复执行或明确记录不可逆步骤与恢复办法。
- 明确事务边界；避免把跨多个业务职责的操作放进隐式的大事务。
- 批量和关联数据访问时检查查询次数，避免明显的 N+1；基于实际查询与数据规模决定索引和优化。
- 数据访问和业务决策保持清晰边界，使用项目已采用的数据库工具链。

> 当前 Validator 没有项目级 Migration 工具和路径配置，因此本规则是人工遵循的 recommended 规则，不代表 `eng validate` 已自动检查 Migration。
