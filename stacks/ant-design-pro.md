# Ant Design Pro

**等级：recommended**

适用于 Profile 声明 `stack.frontend.adminScaffold: ant-design-pro` 的 React 管理后台。

- 先识别项目采用的 Ant Design Pro 版本和脚手架形态，并依照对应的官方文档、路由和配置机制开发；不要混用不同代际模板的目录约定。
- 保留脚手架已有的路由、布局、权限、请求和主题机制；新增页面应沿用仓库已有模式，避免再建立并行的菜单或访问控制系统。
- 权限配置只负责界面显示与导航体验，服务端仍必须逐请求执行身份和资源授权检查。
- 对生成器产物和模板配置做最小必要修改；升级模板或依赖时审查生成文件、锁文件及配置迁移差异。
- 移除示例代码时同步检查路由、菜单、国际化、权限声明、mock 和文档，确保没有面向生产的演示入口。
- 核验构建、路由访问、表单校验和错误处理；对通用 Pro 组件建立项目内一致使用约定，避免页面自行重复封装。

参考：[Ant Design Pro 文档](https://pro.ant.design/)。
