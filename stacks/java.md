# Java 技术栈

**等级：recommended**

适用于 Profile 声明 `stack.backend.language: java` 的项目。

- 在项目已有的 Java 构建和框架约定内组织模块，不另建平行的通用框架。
- 依赖管理、测试、并发和代码风格应使用仓库已选工具链中的一致约定；引入额外工具前说明缺少的能力。
- 并发代码应明确线程/任务所有权、取消和失败传播；不要把共享可变状态默认暴露给多个执行单元。
- 对框架生成代码和业务逻辑保持清晰边界，避免把容器配置当作领域逻辑。

本规则不规定 Java 或 Spring 的具体版本；项目应以自身已锁定版本和官方兼容文档为准。
