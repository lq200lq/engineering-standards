# Ant Design（React）

**等级：recommended**

适用于 Profile 声明 `stack.frontend.uiLibrary: ant-design` 的 React 项目。

- 使用组件库提供的语义化组件和设计令牌；只有在组件不能表达产品需求时才增加局部定制，避免覆盖全局样式造成跨页面副作用。
- 统一主题、国际化、日期处理和反馈组件配置；同一产品流程避免并用多套 Modal、表单、通知或图标方案。
- 表单应定义字段校验、提交中、成功和失败状态；表格应处理分页、筛选、排序及空状态，并将服务端数据边界显式化。
- 按需导入组件和图标，检查构建产物；不要复制整套组件代码或引入重复的组件实现。
- 使用组件库版本对应的 API 与迁移指南，升级时验证主题、样式、表单和复杂交互的回归。
- 保持键盘操作、焦点可见、标签与错误提示等无障碍行为；视觉组件不替代语义和可访问名称。

参考：[Ant Design React 文档](https://ant.design/docs/react/introduce)。
